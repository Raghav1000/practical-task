## 🧩 Admin App (Frontend)

### ✅ Implemented Features
- User CRUD (Create, Read, Update, Delete)
- Search & Pagination
- React Query for API handling
- Redux Toolkit for state management

### ⚠️ Known Skips / Assumptions
1. **Password encryption is skipped from the frontend** (handled in backend).
2. **Authentication route protection is skipped**
3. UI is limited to **User management only i.e. Admin view**.
4. Only **basic form implementation** is implemented.

### 🔧 Suggested Enhancements
- Add protected routes with JWT guards
- Add Post management UI
- Client UI for customers
- Improve UI/UX
